# Student Management System Mini Project

A console-based Python application to perform complete CRUD (Create, Read, Update, Delete) operations on student records using Object-Oriented Programming (OOP) principles.

## 📌 Features
- **Add Student:** Register new students with details like name, age, roll number, marks, and maximum marks.
- **Display All Students:** View a list of all registered students along with their calculated percentage and PASS/FAIL result.
- **Search Student:** Quickly locate student records using their unique roll number.
- **Update Student:** Modify existing details (name, age, marks) of a student by roll number.
- **Delete Student:** Remove student records from the system.
- **Interactive CLI Menu:** User-friendly menu for smooth navigation.

## 🛠️ Tech Stack
- **Language:** Python 3 (OOP concepts, Conditionals, Loops, Functions)
